# 📊 Mobile Sales Dashboard | Power BI

An interactive Mobile Sales Dashboard developed using Microsoft Power BI to analyze mobile sales performance and business insights.

## 🚀 Project Overview

This dashboard provides insights into:

- Total Sales
- Total Quantity
- Total Transactions
- Sales by City
- Monthly Trends
- Brand Performance
- Mobile Model Performance
- Payment Method Analysis
- Customer Ratings
- Day-wise Sales

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization
- Business Intelligence

## 📊 Dashboard Highlights

- Total Sales: 59M
- Total Transactions: 291
- Total Quantity: 1K+
- Brand-wise Sales Analysis
- Mobile Model Analysis
- Payment Method Analysis
- City-wise Sales Map
- Monthly Trend Analysis

## 🎯 Project Objective

The objective of this project is to transform raw mobile sales data into an interactive Power BI dashboard and generate meaningful business insights.
